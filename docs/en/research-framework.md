# Warranted Research Framework

Warranted is a general research framework, not a writing tool.

The resident agent owns the Toulmin layer: Claims, Grounds, Warrants, Backings, Rebuttals, compile state, and earned verdicts.

Object-layer work should be delegated by default when it requires independent search, source reading, experiment execution, data analysis, statistical checking, implementation, citation audit, artifact inspection, or blocker interrogation.

Subagents return evidence reports. They do not own Claim status, mutate the graph, or revise the argument structure unless explicitly instructed. The main agent interprets reports as graph consequences.
